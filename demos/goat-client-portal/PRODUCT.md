# GOAT client portal

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated from the user's request: static HTML, CSS, and JavaScript inside the existing OwnYourWeb GitHub Pages demo repository.

## Users

Anisa is the primary user. She needs one place to check progress and receive files for the GOAT text-logo project.

## Product Purpose

Give Anisa a simple project dashboard where she can enter a temporary access code, see the current logo-work stage, and find project files when they become available.

## Positioning

The portal turns a design project into a visible process. The client can see what is happening without asking for a separate update.

## Operating Context

Anisa opens a private-feeling shared link, enters a temporary code, reviews the project stage, and checks the file area. The file area is empty at launch because no logo files have been added yet.

## Capabilities and Constraints

- The temporary access code is `GOAT-ANISA`.
- GitHub Pages is static. The access screen discourages casual viewing but does not provide secure authentication.
- The demo does not upload, store, or deliver private files.
- The file area must state that no files are ready instead of showing invented deliverables.
- The project is a text-logo project. The final logo, colors, and broader brand direction are still in progress.

## Brand Commitments

- Client name: Anisa.
- Business name: GOAT.
- Keep the working visual identity neutral until the logo direction is approved.
- The interface must feel professional and client-ready, not like a generic admin template.

## Evidence on Hand

No logo concepts, approved colors, downloadable files, timeline, payment status, or client contact details were supplied. Do not fabricate them.

## Product Principles

- Make the current project stage clear in one glance.
- Use honest empty states.
- Keep client actions simple.
- Separate a demo access screen from real security claims.

## Accessibility & Inclusion

Use keyboard-accessible controls, visible focus, readable contrast, responsive layouts, and reduced-motion support.
